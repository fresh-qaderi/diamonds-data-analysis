# Diamonds Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a diamonds dataset using Python.

The main objective is to explore diamond characteristics, examine their relationships with prices, and investigate the distribution of diamonds across different quality grades.

## Dataset

The dataset is stored in `diamonds.xlsx` and contains information about diamond characteristics and quality attributes.

## Data Analysis Objectives

The analysis addresses the following questions:

1. Does diamond price increase with carat weight?
2. Which clarity grade is the most common among diamonds?
3. Does cut quality affect diamond prices?
4. What is the percentage distribution of diamonds across different color grades?
5. Are diamonds with higher clarity grades more expensive?
6. How are diamond prices distributed across different clarity grades?
